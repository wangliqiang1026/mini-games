# 🍉 合成大西瓜 · Merge Watermelon

一款零依赖、单页、移动端优先的物理合成小游戏，专为 **Google AdSense 流量变现**设计：
上手 3 秒、一局 2~3 分钟、天然的"再来一局"循环 + 一键分享成绩，具备爆款传播的完整闭环。

## 游戏玩法

- 移动瞄准，松手把水果丢进果盘（手机拖拽 / 鼠标点击 / 键盘 ←→ + 空格）
- 两个相同水果碰撞 → 合成更大的水果（樱桃 → 草莓 → … → 西瓜）
- 短时间内连续合成触发**连击倍率**（最高 x5）
- 水果堆过黄色警戒线约 1.6 秒即结束；两个西瓜合体会消散并奖励 +200 分
- 最高分自动保存在浏览器本地

## 技术特性

- **零依赖**：纯原生 HTML/CSS/JS + Canvas，无框架、无图片/音频资源（水果为 Canvas 矢量绘制、音效为 WebAudio 合成），首屏极快，利于 SEO 与广告加载
- **自研轻量物理引擎**：冲量求解 + 位置修正，稳定堆叠不爆炸
- **全端适配**：手机竖屏、桌面、高分屏（DPR 2x 超采样）均清晰
- 高级特效：粒子迸发、彩带、屏幕震动、危险线倒计时、连击飘字

## 接入 Google AdSense（3 步）

1. **申请**：到 [adsense.google.com](https://adsense.google.com) 添加你的域名并提交审核（需要域名可访问、有隐私政策页——已为你备好 `privacy.html`）
2. **改配置**：打开 `index.html`，只改底部这一处：
   ```js
   window.AD_CONFIG = {
     client: "ca-pub-XXXXXXXXXXXXXXXX",        // ← 你的发布商 ID
     slots: {
       top: "0000000000",                      // ← 顶部横幅广告单元 ID
       bottom: "0000000000",                   // ← 底部横幅广告单元 ID
       modal: "0000000000"                     // ← 结算弹窗广告单元 ID
     }
   };
   ```
   在 AdSense 后台「广告 → 按广告单元」创建 3 个**展示广告**单元，把单元 ID 填进来。
3. **改 ads.txt**：把 `ads.txt` 里的 `pub-XXXXXXXXXXXXXXXX` 换成你的发布商 ID（不带 `ca-` 前缀），文件保持在网站根目录。

配置完成前，页面只显示虚线占位框，**不会加载任何广告代码**；配置后自动生效。

### 合规注意事项（务必阅读）

- **不要点击自己的广告**，也不要让朋友/家人代点，会导致封号
- 保留 `privacy.html`（AdSense 强制要求，记得把里面的联系邮箱换成你的）
- 不要诱导用户点击广告（本模板已按政策预留了广告与按钮的安全间距）
- AdSense 审核期间保持站点可访问，通常 1~14 天出结果
- 提高通过率与流量建议：绑定独立域名、提交 Google Search Console、在站内再增加 1~2 个说明页/博客内容
- 「合成大西瓜」玩法存在大量同类产品，若用于商业运营，建议后续替换为自己的游戏名称与美术风格

## 常见问题

**广告不显示？**
依次检查：① `AD_CONFIG.client` 是否已替换；② 广告单元 ID 是否真实；③ `ads.txt` 是否可经 `你的域名/ads.txt` 访问；④ 新站/新单元通常需要几分钟到几小时才开始投放；⑤ 关闭浏览器广告拦截插件再试。

**最高分存在哪里？** 浏览器 localStorage（`watermelon_best`），清缓存会丢失，无后端。

## 想调难度 / 换皮肤？

常用参数都在 `js/game.js` 顶部：

| 参数 | 默认 | 含义 |
|---|---|---|
| `COOLDOWN` | 0.5 | 两次投掷最小间隔（越小节奏越快） |
| `OVER_TIME` | 1.6 | 压线判负时间（越大越宽容） |
| `COMBO_WINDOW` | 0.9 | 连击判定窗口（秒） |
| `SPAWN_WEIGHTS` | [30,26,20,15,9] | 前 5 档水果出现权重 |

水果大小、配色、名字在 `js/fruits.js` 的 `FRUITS` 数组中，增删改即可换主题（例如节日皮肤）。
